# 💫 About Me:
Apple Navigation and software Development Post QA Reviewer Quality Analyst GIS Engineer<br>MSc in Applied Geography and Geoinformatics from Central University of Karnataka<br>GIS Engineer with 3 years delivering enterprise-scale spatial data quality for Apple Maps via RMSI — one of the world's most widely used digital mapping platforms.
